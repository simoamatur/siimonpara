# ERP Pharmaceutique - B2B Management System

## 📋 Description du Projet

Système ERP (Enterprise Resource Planning) moderne et complet dédié à la gestion pharmaceutique B2B. Cette application web permet de gérer l'ensemble des processus d'achat, vente, stock et comptabilité pour une entreprise de distribution pharmaceutique. L'interface a été entièrement refactorisée avec un design épuré et reposant pour les yeux, intégrant un système de 3 thèmes visuels.

### 🎯 Objectifs Principaux

- **Digitalisation complète** des processus métier (achats, ventes, stocks)
- **Interface moderne 2026** avec animations fluides et UX optimisée
- **Système de 3 thèmes visuels** (Clair, Sombre, Nature) pour personnalisation
- **Design reposant pour les yeux** - palette de couleurs douces et adoucies
- **Gestion multi-rôles** (admin, commercial, livreur, client)
- **Traçabilité totale** des mouvements et documents
- **Automatisation** des tâches récurrentes

### 🎨 Système de Thèmes (3 Modes)

Le dashboard intègre un sélecteur de thème à 3 options situé dans le header :

| Thème | Couleur de Fond | Icône | Usage |
|-------|-----------------|-------|-------|
| **☀️ Clair** (`light`) | `#F5F9F7` (Vert très clair) | Sun (Lucide) | Mode par défaut, reposant |
| **🌙 Sombre** (`dark`) | `gray-950` | Moon (Lucide) | Travail nocturne |
| **🍃 Nature** (`warm`) | `#FAF8F5` (Beige chaud) | Leaf (Lucide) | Ambiance douce/cosy |

**Implémentation technique** :
- Type TypeScript : `type Theme = 'light' | 'dark' | 'warm'`
- State global dans `DashboardLayout.tsx`
- Configuration centralisée : `THEME_CONFIG` record
- Transition CSS fluide : `transition-colors duration-300`
- Sélecteur visuel : 3 boutons icônes avec état actif (fond blanc/ombre)

## 🎨 Design System

### Refactoring UI/UX - Thème Clair & Reposant

#### 🎯 Objectif du Refactoring
Transformation du design sombre original vers une interface claire et apaisante pour réduire la fatigue visuelle.

**Ancien vs Nouveau design** :
- ❌ Avant : Fonds `slate-900`, `slate-950`, textes blancs sur noir
- ✅ Après : Fonds `gray-50` à `gray-100`, textes gris doux, accents verts menthe

#### Palette de Couleurs - Brand

Définies dans `src/index.css` via `@theme` :

| Variable CSS | Valeur | Description |
|--------------|--------|-------------|
| `--color-brand-primary` | `#5AAF9F` | Menthe douce - Principal |
| `--color-brand-secondary` | `#7BC4B8` | Vert clair - Secondaire |
| `--color-brand-accent` | `#E8F5F2` | Vert pastel très clair |
| `--color-paper` | `#FAFBF9` | Blanc cassé chaud |

#### Mapping des Couleurs (Refactoring Global)

Propagation automatique sur 74 fichiers via script Node.js :

| Ancien (Slate foncé) | Nouveau (Gray doux) | Fichiers affectés |
|---------------------|---------------------|-------------------|
| `text-slate-900` | `text-gray-700` | 65+ |
| `text-slate-800` | `text-gray-700` | 65+ |
| `text-slate-700` | `text-gray-600` | 65+ |
| `text-slate-600` | `text-gray-500` | 65+ |
| `text-slate-500` | `text-gray-400` | 65+ |
| `bg-slate-50` | `bg-gray-50` | 65+ |
| `bg-slate-100` | `bg-gray-100` | 65+ |
| `bg-slate-800/900/950` | Supprimé ou `bg-gray-800` | 9+ pages |
| `border-slate-200` | `border-gray-200` | 65+ |
